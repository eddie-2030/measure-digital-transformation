# Data dictionary: E03 AI Tutors in Practice

All data in this folder are synthetic, generated to illustrate the method. They do not come from Meta, any client, or any real organization. The goal is to show how a business question, a measurement strategy, the statistics, and the code connect end to end.

Generated by `generate_data.py` (seed 20261106). 1,200 learners, 60 teams, 3 business units, 96,866 logged actions.

## tutor_events.csv (one row per logged tutor action; the analyst's main input)

| column | type | meaning | units / values |
|---|---|---|---|
| learner_id | string | Learner identifier | L0001 to L1200 |
| session_id | string | Tutor session, unique across the file | `<learner_id>_S<nn>` |
| step | integer | Order of the action within its session | 1, 2, 3, ... |
| action | string | Coded learner action | T attempt, H hint/explanation, A full answer, C copy/paste AI answer, V verify own work, Q quit (end of session). Messy on purpose: some codes are lower case or have stray spaces (" h"), about 0.3% are unreadable ("?"), about 2% are mis-coded |
| timestamp | string | Time of the action | ISO 8601, `YYYY-MM-DDTHH:MM:SS`, course runs 7 Sep to 1 Nov 2026 |

Notes: a session normally ends with Q. About 5% of sessions end without Q (logout or time-out). About 2% of learners have a single very short session (1 to 3 actions).

## learners.csv (one row per learner)

| column | type | meaning | units / values |
|---|---|---|---|
| learner_id | string | Learner identifier | L0001 to L1200 |
| team_id | string | Team; each team has its own course instructor | TM01 to TM60 |
| business_unit | string | Business unit | Finance & Risk, Operations, Sales & Marketing |
| pre_score | integer | Pre-test score on the common assessment | 0 to 100 points |
| post_score | integer or blank | Post-test score after 8 weeks | 0 to 100 points; blank for 18 learners with no post-test |
| split | string | Held-out evaluation split, by learner (fixed by the generator) | train (70%), test (30%) |

Derived in the analysis: `gain = post_score - pre_score` (points); `gained = 1 if gain >= 10`.

## ground_truth.csv (for the ground-truth check only; not available in real life)

| column | type | meaning | units / values |
|---|---|---|---|
| learner_id | string | Learner identifier | |
| true_style | string | Latent usage style used to simulate the learner's actions | scaffolded, answer_seeking, light_mixed |
| expected_gain | number | Noise-free expected gain (style effect + prior-skill term + instructor effect) | points |
| early_dropout | integer | 1 if the learner was simulated as an early drop-out (one very short session) | 0/1 |

## ground_truth_transitions.csv

| column | type | meaning |
|---|---|---|
| style | string | scaffolded, answer_seeking, light_mixed |
| from_state | string | Current state: START, T, H, A, C, V |
| to_token | string | Next token: T, H, A, C, V, Q |
| true_prob | number | True P(next = to_token given current = from_state) for that style |

## ground_truth_params.json

Every true parameter in one file: target and realized style shares, the style model (multinomial logit on pre-test), the three transition matrices, sessions per learner, dwell times, the gain model, the messiness rates and the test share.
